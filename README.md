# vxdatalabs

TPM who builds. I got tired of waiting for the right tools, so I wrote them: alerts that never sleep, scanners that rank the noise, and a vision model that reads charts. Python first, shipped and running.

## Projects

- **[news-alert-system](https://github.com/vxdatalabs/news-alert-system)**: always-on stock headline alerts. Finnhub → Telegram/Discord, running as a systemd service on Oracle Cloud.
- **[wyckoff-chart-labeler](https://github.com/vxdatalabs/wyckoff-chart-labeler)**: upload a chart, a vision model labels Wyckoff structure, and the overlay snaps to real candles.
- **[momentum-scanner](https://github.com/vxdatalabs/momentum-scanner)**: ranks swing-momentum setups, then checks if the options are actually worth trading.
